# Rabee Ghanem - Portfolio

A modern, responsive portfolio website built with React.js and Vite. Features dark/light mode, bilingual support (English/Arabic), and smooth animations.

## Features

- 🌙 Dark/Light mode toggle
- 🌍 Bilingual support (English/Arabic)
- ✨ Smooth scroll animations
- 📱 Fully responsive design
- 🎯 Modern UI with glassmorphism effects
- 📊 Interactive skill sections
- 📞 Contact form
- ⚡ Fast loading with Vite

## Tech Stack

- **Frontend:** React.js
- **Build Tool:** Vite
- **Styling:** CSS with custom properties
- **Animations:** React Intersection Observer, TSParticles
- **Icons:** Font Awesome
- **Fonts:** Google Fonts (Tajawal, Inter, Montserrat)
